# Amazon Product Analysis

## Project Overview
This project focuses on analyzing Amazon product data to understand product pricing, discounts, ratings, customer reviews, and category-wise product distribution. Python and Power BI are used to clean, analyze, and visualize the data.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL (SQLite)
- Microsoft Power BI
- Jupyter Notebook

## Project Objectives
- Clean and preprocess Amazon product data.
- Analyze actual prices and discounted prices.
- Identify products with high ratings and review counts.
- Explore discount patterns across products.
- Analyze product distribution across categories.
- Build an interactive Power BI dashboard.

## Dataset Information
The dataset contains product details such as product names, categories, actual prices, discounted prices, discount percentages, ratings, and rating counts.

- Original dataset: `amazon.csv`
- Cleaned dataset: `amazon_cleaned.csv`
- SQLite database: `amazon_analysis.db`

## Key Findings
- **Total Records:** 1,465
- **Unique Product IDs:** 1,351
- **Average Discounted Price:** ₹3,125.31
- **Average Actual Price:** ₹5,444.99
- **Average Discount:** 47.69%
- **Average Product Rating:** 4.10/5

## Dashboard
An interactive Power BI dashboard was created to visualize key performance indicators, product categories, pricing comparisons, ratings, and discount patterns.

## Project Structure
- `Amazon_Product_Analysis.ipynb` — Data cleaning and analysis
- `amazon.csv` — Original dataset
- `amazon_cleaned.csv` — Cleaned dataset
- `amazon_analysis.db` — SQLite database
- `Amazon_Product_Analysis_Dashboard.pbix` — Power BI dashboard

## Skills Demonstrated
Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, SQL, Python, and Power BI.
